# Το Νηπιαγωγείο μας

Ελληνικό responsive παρουσιολόγιο με Supabase και εγκατάσταση PWA.

Κοινά παιδιά, παρουσίες, φωτογραφίες, ιστορικό και στατιστικά για εγκεκριμένους εκπαιδευτικούς. Οι ρυθμίσεις και η έγκριση email γίνονται από τον διαχειριστή.

## Νέοι εκπαιδευτικοί

1. Ρυθμίσεις → Πρόσβαση εκπαιδευτικών → Έγκριση email.
2. Supabase → Authentication → Users → Add user → Create new user, με επιβεβαιωμένο email.
3. Σύνδεση στην εφαρμογή με προσωπικό email και κωδικό.

Η έγκριση δεν στέλνει πρόσκληση. Η πρόσβαση ελέγχεται με RLS και proini_members. Το frontend περιέχει μόνο publishable key.

## Εγκατάσταση

https://danal8.github.io/to-nipiagogeio-mas/

Android: Chrome → Εγκατάσταση εφαρμογής. iPhone: Safari → Κοινοποίηση → Προσθήκη στην οθόνη αφετηρίας.

Το service worker αποθηκεύει μόνο στατικά αρχεία. Η σύνδεση και αποθήκευση παρουσιών χρειάζονται Internet. Δεν αποθηκεύονται δεδομένα παιδιών στην cache του service worker.
