# Το Νηπιαγωγείο μας

Responsive εφαρμογή παρουσιολογίου πρωινής υποδοχής στα ελληνικά, με pastel UI και Supabase.

## Λειτουργίες

- Κάρτες παιδιών, φωτογραφία, ονοματεπώνυμο, φύλο, τμήμα και ημερομηνία γέννησης.
- Παρών / Απών για αγόρια, Παρούσα / Απούσα για κορίτσια.
- Αρχική κατάσταση «Δεν καταχωρήθηκε» και αναίρεση επιλογής.
- Αυτόματη ώρα άφιξης για τη σημερινή ημερομηνία, στη ζώνη Europe/Athens.
- Αναζήτηση χωρίς τόνους, φίλτρα τμήματος και κατάστασης.
- Ιστορικό παιδιού, βασικά στατιστικά και ρυθμίσεις σχολικής χρονιάς/ωραρίου.
- Σύνδεση χρήστη και αποθήκευση στο Supabase. Δοκιμαστική λειτουργία με ενδεικτικά παιδιά μόνο στη συσκευή.

## Εκκίνηση

Ανοίξτε το `index.html` με σύγχρονο browser και σύνδεση στο Internet ή σερβίρετε τα αρχεία με έναν τοπικό HTTP server.

Για πραγματικά δεδομένα χρησιμοποιήστε email/κωδικό υπάρχοντος χρήστη στο Supabase Auth του project `htlifrjwigbeqijsqzxn`. Η σύνδεση στο dashboard του Supabase δεν αποτελεί λογαριασμό της εφαρμογής.

## Βάση δεδομένων

Οι πίνακες `proini_children`, `proini_attendance`, `proini_settings` έχουν ήδη δημιουργηθεί στο συνδεδεμένο project. Οι πολιτικές RLS περιορίζουν την πρόσβαση στα δεδομένα του συνδεδεμένου χρήστη. Το frontend περιέχει μόνο publishable key, χωρίς service-role key.

Στην πρώτη έκδοση κάθε λογαριασμός έχει το δικό του σύνολο παιδιών. Η κοινή διαχείριση από πολλούς εκπαιδευτικούς δεν έχει ακόμη υλοποιηθεί. Οι φωτογραφίες συμπιέζονται σε JPEG 320×320 και αποθηκεύονται με την καρτέλα στη βάση.

## Έλεγχοι

Ελέγχθηκαν η σύνταξη JavaScript, προσθήκη παιδιού, παρουσία/απουσία, αυτόματη ώρα, αναζήτηση, ιστορικό και στατιστικά στη δοκιμαστική λειτουργία, καθώς και διατάξεις κινητού/tablet. Ελέγχθηκε η απομόνωση χρηστών στη βάση. Η πραγματική είσοδος και το upload φωτογραφίας χρειάζονται τελική δοκιμή με τον λογαριασμό του χρήστη.
